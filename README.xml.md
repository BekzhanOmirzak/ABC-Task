# ABC-Task (XML)

This document describes the XML + Views implementation.

## Branch

- `xml`

## Tech Stack

- Kotlin
- XML Layouts + Android View system
- Android Jetpack (Lifecycle, ViewModel)
- Coroutines + StateFlow
- Gradle (Kotlin DSL + Version Catalog)
- No third-party libraries

## Run XML Version

```bash
git checkout xml
./gradlew assembleDebug
```

Open the project in Android Studio and run the app on an emulator or device.

Switch to the `compose` branch and use [`README.compose.md`](README.compose.md).
